# 薩摩耶課堂隨機點名

可直接部署的單頁課堂隨機點名工具。此 GitHub 參考版僅保留示範名單，不含任何真實學生個資。

## 功能

- 從全班未點名學生中隨機抽出指定人數
- 每組各抽一人
- 兩步驟模式：先抽組別，再抽該組學生
- 本堂已抽學生不重複；可按「重設本堂紀錄」重新開始
- 點名紀錄保存在瀏覽器的 localStorage

## 替換名單

開啟 `index.html`，找到 `const groups = [...]`，依以下格式替換：

```javascript
const groups = [
  {name:'第一組', students:[['王小明','01'],['李小華','02']]},
  {name:'第二組', students:[['陳小美','03'],['林小安','04']]}
];
```

每位學生格式為 `['姓名','座號']`。請勿將真實學生名單上傳到公開 GitHub；若需版本控制，請建立 Private repository。

## 使用與部署

這是純 HTML/CSS/JavaScript 網頁，不需安裝套件。直接開啟 `index.html` 即可使用；也可部署到 GitHub Pages、Netlify 或 Cloudflare Pages。

## 隱私提醒

公開版本只能使用示範或去識別化資料。含姓名、學號、座號等可識別資訊的版本，應使用私有儲存庫或受權限控管的部署方式。
